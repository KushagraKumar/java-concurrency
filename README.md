# Java Concurrency Staff+ Roadmap Repo
## 🚀 Quick Start
\`\`\`bash
mvn clean compile test
\`\`\`
## 🧭 How to Use
1. Pick a phase → read concepts → run reference snippets
2. Implement the \`TODO\`s in \`phaseX/problems/\`
3. Validate with \`ConcurrentTestHarness\` + JUnit
4. Benchmark contention with JMH (\`jmh/java/...\`)
5. Profile with \`scripts/run-jfr-recording.sh\` + async-profiler
6. Document trade-offs, failure modes, and observability strategy
